Overheard vs Anarlog (formerly Hyprnote)

Checked against Anarlog's site and GitHub repository on 31 October 2026

Anarlog, the open-source app that used to be called Hyprnote, and Overheard are closer than any other pair here: both record your calls without a bot, both can transcribe on your Mac, both are MIT licensed and both speak MCP. The difference is shape. Anarlog is a full AI notepad with an optional cloud and team plan; Overheard is a small menu bar recorder that keeps each meeting as plain files and leaves the thinking to Claude.

Pick Anarlog if…

you want a notepad you type into during the meeting, local models through Ollama or LM Studio, encrypted sync between machines, or shared team workspaces.

Pick Overheard if…

you want a recorder that stays out of the way, meetings as plain Markdown folders any tool can read, and Claude Code, Claude Desktop or Codex as the place you ask questions.

Where Anarlog is better

A real notepad. Anarlog is built around notes you write during the meeting, which AI then fills in. Overheard has no editor for live notes: it records, then summarizes.

Any model you like. Anarlog can use an OpenAI-compatible local server such as Ollama or LM Studio, or several hosted providers. Overheard's summaries go through Claude Code, Codex or Apple Intelligence only.

Sync and teams. Pro adds encrypted sync, shared folders, roles and SSO for companies. Overheard has no accounts and no server.

A bigger project. Anarlog has a funded team and a large community behind it. Overheard is built by one person.

Where Overheard is better

Plain files, not a database. Every Overheard meeting is a folder with the audio, a Markdown transcript and a Markdown summary. Obsidian, grep, Spotlight, git or a sync tool can read them as they are, with no export step.

Everything free, no Pro. There's no paid tier: speaker labels on-device, MCP actions and unlimited history are all in the free app.

Claude-first. Overheard ships a Claude Code plugin with /overheard:recap, /overheard:followup and /overheard:todo, and uses the Claude subscription you already pay for — no extra API keys. Read how it works.

Starts on its own. Overheard lives in the menu bar and starts recording when Meet, Teams or Slack take the microphone, with a global shortcut to bookmark a moment. Native Swift, small and quiet.

Switching

Both apps just listen to your Mac's audio, so you can run them side by side. Export old meetings from Anarlog as Markdown for your archive, or drop their audio files into Overheard's Import to make them searchable from Claude.
